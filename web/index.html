Remote Sensing Spectral Index Guide

Sentinel-2 MSI Analysis Ready Data

False Colour SWIR (Burn Scar Emphasis)

Formula: R = B12 (SWIR-2), G = B8A (Narrow NIR), B = B04 (Red)

Combines Short-Wave Infrared with Near-Infrared to penetrate atmospheric smoke haze and highlight charred organic matter.

Scientific Caveat: SWIR bands have 20m spatial resolution. Bare dry red soil or rocky terrain can mimic burn scar reflectance.
